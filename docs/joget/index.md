# Joget DX9 Code Library

Searchable examples for **theme CSS, UI JavaScript, forms, Data Lists, navigation and responsive design**.

| Name | Code type | Primary purpose |
|---|---|---|
| [Hide Default Page Heading](hide-page-heading.md) | CSS | Hide `h4.page-heading` |
| [Theme JavaScript](theme-javascript.md) | JavaScript | Avatar, attendees placeholder, moving meeting button, grid Add style cleanup |
| [calmViolet](calmviolet.md) | CSS | Entire Joget UI design layer |
| [ECharts Studio](echarts-studio.md) | CSS | Dashboard cards, help pages, page headings |
| [Dark Green Route Panel](dark-green-route-panel.md) | CSS | Sidebar colour, mobile lists, slider panel |

!!! warning "CSS is presentation, not security"
    Hiding buttons, headings, columns, or admin controls using CSS does not enforce permissions. Configure access using Joget's actual roles, permissions and security settings.

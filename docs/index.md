## Our rules

1. **Preserve the original complete code.** Extract smaller reusable snippets as separate files.
2. **Explain what it does** and where it belongs in Joget or other applications.
3. **Record risks and tested status.** CSS hiding a control is not the same as permissions.
4. **Avoid private information.** Only publish material approved for the repository's visibility.
5. **Prefer small, reusable snippets** over copying entire themes into every project.

# Start Here

CodeVault KB is a searchable website built from plain text files in GitHub.

## For readers

- Use **Search** in the top navigation. Search by a problem (*hide heading*), Joget component (*Form Grid*), CSS selector (*page-heading*), or category (*theme*).
- Open an article to see purpose, code, installation steps, test status and risks.
- Copy code into an appropriate **test Joget Userview**, not directly into production.
- Follow the link to the complete source file if the article only shows a short snippet.

## For editors

- Sign in to GitHub and edit the article or original code file. Describe what changed in the commit message.
- Submit a pull request if your team requires review.
- Once changes reach `main`, the GitHub Pages workflow publishes them automatically.

## Version history and backups

GitHub tracks earlier commits, so you can compare changes or restore previous versions. Periodically download or clone the complete repository for an independent backup.
